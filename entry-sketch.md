# Entry Sketch — Kampot Durian Archive

What one entry in this archive looks like, as data.

| Field | Required? | Notes |
|---|---|---|
| title | required | short name for the entry, e.g. "First harvest of the season" |
| khmer name | required | the Khmer term or name for the tree, variety, or practice |
| the story itself | required | the actual account, in the source's words where possible |
| source | required | who told the story — a family member, farmer, neighbor |
| place | required | where on the farm / in Kampot this happened |
| date | optional | when it happened, or approximate season/year |
| photo or audio | optional | supporting media if available |
| tags | optional | e.g. "harvest", "grafting", "monsoon", "market" |

Cut: no need for GPS coordinates or a formal citation format — this is a family farm, not an academic archive.
